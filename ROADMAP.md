## Where it stands (2026-10-25)

- **Current (branch `VNO-49_local-voice-engines`, pending merge):** VNO-49 replaces VibeTTS with the local ComfyUI voice engines (TTS Audio Suite). OmniVoice is the default engine and reads Croatian; Higgs Audio v3, Chatterbox 23L, VibeVoice, Qwen3-TTS, IndexTTS-2 and F5-TTS are selectable per language (`voice.engine` / `voice.engines`), with uploaded reference clips, their transcripts (`voice.refTexts`) and delivery styles (`voice.styles`). Google Flow voices remain as the demoted cloud fallback. Sound effects can use MOSS-SoundEffect v2 explicitly, alongside every audio engine, custom workflows and Chiptune Studio; the default stays the ambience engine (Chiptune for pixel books, `none` import-only) because the installed `comfyui_fill-chatterbox` node breaks the MOSS VAE loader with its `torch.load` patch. Voice clips can be regenerated (`vno_voice_generate {force}`, Regenerate in the Voice tab), and local engines list before Flow. Local-first: an unchanged project makes no ComfyUI request.
- **Merged 2026-10-25 (PR #20):** VNO-46 imports a Scriptorium pack directly, adds catalog editions by ID (no alignment/aligner/asset job), derives asset IDs only from the template, adds `sceneTitles`, Croatian puzzle UI keys, edition voice languages and `vno_sync_editions`. 1071 tests, typecheck and lint green; live soother builds en+hr with 53 assets unchanged. Plan/changelog in `.claude/tickets/VNO-46-vn-pack/`.
- **Merged 2026-10-25 (PR #22):** VNO-48 gives the HTML5 Web Player a readable, theme-aware Preferences screen (visible close button, sectioned rows, themed selects/ranges, value readouts), splits the **interface language** (every built-in language with menu strings, English first, remembered in `localStorage`) from the **story language** (the book's editions), so changing one never changes the other; makes the picture-book caption auto-fit its strip instead of covering the illustration, adds a 80–140 % story text size, and balances the mix (music default 48, perceptual gain curve, music/ambience ducking under the voice, one-time migration of old saved settings). 1106 tests in 81 files, typecheck and lint green.
- **On branch `VNO-41_screen-language-switcher`:** VNO-41 adds a persistent top-right stage HUD language switcher (`#vno-lang-bar` / `#vno-stage-language`) accessible on every screen in the HTML5 Web Player (`src/engine/game/player-runtime.ts`, `src/engine/game/emit.ts`), live-updating the active screen (Main Menu, Chapter Card, Dialogue + character aliases + emphasis, Branching Choices, Interactive Puzzles preserving struck clues, History log, Save/Load, Preferences, About, and Ending Card) and continuing in the selected language for all subsequent beats and scenes; 976 tests in 69 files pass, typecheck and lint clean.
- **Merged:** VNO-04 to VNO-40. VNO-08 closed every VN Studio item of the hub roadmap.
- **Verified live:** two *Clockless God* VNs (linear and with choices) built from Scriptorium scripts and played by the user; a pixel-art book with Claude as the client for the model roles; story tools with German, English and Arabic editions.

- **VNO-48** (2026-10-25; plan `.claude/tickets/VNO-48-player-preferences-and-languages/plan.md`, changelog `.claude/tickets/VNO-48-player-preferences-and-languages/changelog.md`): the web player's Preferences screen is rebuilt on theme-aware `--vno-ui-*` tokens computed from the palette (contrast-checked panel/control/text colours, a visible 52 px close button with an accessible name, focused select/range styling, sectioned Display/Language/Text/Audio cards with value readouts), so it reads on the cream Storybook theme and on dark themes alike.
